# New Seeding Algorithm Implementation

This implementation provides the new provably fair seeding algorithm for bustabit games using a chain of 100,000,000 SHA256 hashes.

## Overview

The system uses:
- A chain of 100M SHA256 hashes generated by recursive hashing
- BLS signatures from VX for each game
- HMAC-SHA256 for game result generation
- Bitcoin block 831500 hash as the game salt

## Constants

- **Terminating Hash**: `567a98370fb7545137ddb53687723cf0b8a1f5e93b1f76f4a1da29416930fa59`
- **VX Public Key**: `b40c94495f6e6e73619aeb54ec2fc84c5333f7a88ace82923946fc5b6c8635b08f9130888dd96e1749a1d5aab00020e4`
- **Game Salt**: Hash of Bitcoin block 831500 (lowercase hexadecimal)

## Usage

### Verify a Hash is in the Chain

```typescript
import { hexToBytes } from "@noble/hashes/utils";
import { verifyInChain } from "./seeding.js";

const hash = hexToBytes("70eed5c29bde5132f4e41ec8b117a31533e5b055c6c21174d932b377a1855a04");
const gameId = verifyInChain(hash);
console.log(`Game ID: ${gameId}`);
```

### Validate a VX Signature

```typescript
import { validateSignature } from "./seeding.js";
import { hexToBytes } from "@noble/hashes/utils";

const gameSalt = "hash_of_block_831500"; // Replace with actual block hash
const prevGameHash = hexToBytes("..."); // Previous game hash
const vxSignature = hexToBytes("..."); // VX signature

const isValid = validateSignature(gameSalt, prevGameHash, vxSignature);
console.log(`Signature valid: ${isValid}`);
```

### Calculate Game Result

```typescript
import { gameResult } from "./seeding.js";
import { hexToBytes } from "@noble/hashes/utils";

const vxSignature = hexToBytes("...");
const gameHash = hexToBytes("...");

const crashPoint = gameResult(vxSignature, gameHash);
console.log(`Crash point: ${crashPoint}x`);
```

## API Reference

### `verifyInChain(hash: Uint8Array): number | null`

Verifies if a hash is part of the chain by hashing it recursively until it matches the terminating hash.

- **Parameters**:
  - `hash`: The hash to verify (as Uint8Array)
- **Returns**: The game ID (1-100,000,000) if valid, or `null` if not found

### `validateSignature(gameSalt: string, prevGameHash: Uint8Array, vxSignature: Uint8Array): boolean`

Validates a VX signature using BLS signature verification.

- **Parameters**:
  - `gameSalt`: The hash of Bitcoin block 831500
  - `prevGameHash`: The hash of the previous game
  - `vxSignature`: The VX signature to validate
- **Returns**: `true` if the signature is valid, `false` otherwise

### `gameResult(vxSignature: Uint8Array, gameHash: Uint8Array): number`

Calculates the game result (crash point) from a VX signature and game hash.

- **Parameters**:
  - `vxSignature`: The VX signature
  - `gameHash`: The game hash
- **Returns**: The crash point as a decimal number (e.g., 1.00, 2.50, 10.00)

## Algorithm Details

### Game Result Calculation

1. Compute `HMAC_SHA256(key=signature, message=hash)`
2. Extract the 52 most significant bits as `r`
3. Calculate `X = r / 2^52` (uniformly distributed in [0, 1))
4. Calculate `X = 99 / (1 - X)`
5. Return `max(1, floor(X) / 100)`
