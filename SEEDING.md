# Bustabit Provably Fair Seeding Algorithm

This document describes the new provably fair seeding algorithm implementation for bustabit, including hash chain verification, BLS signature validation, and game result calculation.

## Overview

The algorithm uses a chain of 100,000,000 SHA256 hashes generated by recursively hashing the binary value of the previous hash, starting from a secret. Each hash in the chain generates a game result in a provably fair manner.

### Key Components

1. **Hash Chain Verification** - Verify that a hash is part of the 100M game chain
2. **BLS Signature Validation** - Validate VX signatures to ensure fairness
3. **Game Result Calculation** - Calculate crash points using HMAC-SHA256

## Usage

### Import the Module

```typescript
import { verifyInChain, validateSignature, gameResult } from "./seeding.js";
import { hexToBytes } from "@noble/hashes/utils";
```

### 1. Verify Hash in Chain

Verify if a hash is part of the game hash chain:

```typescript
import { hexToBytes } from "@noble/hashes/utils";
import { verifyInChain } from "./seeding.js";

const hash = hexToBytes("70eed5c29bde5132f4e41ec8b117a31533e5b055c6c21174d932b377a1855a04");
const gameId = verifyInChain(hash);

if (gameId) {
  console.log(`Hash is in the chain. It is game: ${gameId}`);
} else {
  console.log("Hash is not in the chain");
}
```

### 2. Validate VX Signature

Validate that VX has signed the game with their BLS public key:

```typescript
import { hexToBytes, utf8ToBytes } from "@noble/hashes/utils";
import { validateSignature } from "./seeding.js";

const gameSalt = "abc123..."; // Hash of Bitcoin block 831500
const prevGameHash = hexToBytes("70eed5c29bde5132f4e41ec8b117a31533e5b055c6c21174d932b377a1855a04");
const vxSignature = hexToBytes("..."); // VX's BLS signature

if (validateSignature(gameSalt, prevGameHash, vxSignature)) {
  console.log("Signature is valid");
} else {
  console.log("Invalid signature");
}
```

### 3. Calculate Game Result

Calculate the crash point from a VX signature and game hash:

```typescript
import { hexToBytes } from "@noble/hashes/utils";
import { gameResult } from "./seeding.js";

const vxSignature = hexToBytes("...");
const gameHash = hexToBytes("70eed5c29bde5132f4e41ec8b117a31533e5b055c6c21174d932b377a1855a04");

const crashPoint = gameResult(vxSignature, gameHash);
console.log(`Game crashed at: ${crashPoint.toFixed(2)}x`);
```

## Algorithm Details

### Hash Chain

The chain consists of 100,000,000 SHA256 hashes:
- First element: hash of game #100,000,000
- Last element: hash of game #1 (terminating hash)
- Terminating hash: `567a98370fb7545137ddb53687723cf0b8a1f5e93b1f76f4a1da29416930fa59`

### VX Public Key

VX uses the following BLS public key:
```
b40c94495f6e6e73619aeb54ec2fc84c5333f7a88ace82923946fc5b6c8635b08f9130888dd96e1749a1d5aab00020e4
```

### Game Salt

The game salt is the lowercase, hexadecimal representation of the hash of Bitcoin block 831500. This ensures the hash chain was picked fairly before the block was mined.

### Game Result Calculation

The crash point is calculated as follows:

1. `hash = HMAC_SHA256(key=signature, message=gameHash)`
2. `r = 52 most significant bits of hash`
3. `X = r / 2^52` (uniformly distributed in [0, 1))
4. `X = 99 / (1 - X)`
5. `result = max(1, floor(X) / 100)`

This algorithm ensures:
- Uniform distribution of results
- No division by zero (using `1 - X`)
- Minimum crash point of 1.00x
- Provably fair results

## API Reference

### Constants

- **TERMINATING_HASH**: The hash of game #1
- **VX_PUBKEY**: VX's BLS public key
- **MAX_GAME_ID**: Maximum game ID (100,000,000)

### Functions

#### `verifyInChain(hash: Uint8Array): number | null`

Verifies if a hash is part of the game hash chain.

**Parameters:**
- `hash`: The hash to verify (as Uint8Array)

**Returns:**
- Game ID if found, or `null` if not in chain

#### `validateSignature(gameSalt: string, prevGameHash: Uint8Array, vxSignature: Uint8Array): boolean`

Validates a VX signature for a game.

**Parameters:**
- `gameSalt`: The hash of Bitcoin block 831500 (lowercase hex string)
- `prevGameHash`: The hash of the previous game (as Uint8Array)
- `vxSignature`: The VX signature to validate (as Uint8Array)

**Returns:**
- `true` if signature is valid, `false` otherwise

#### `gameResult(vxSignature: Uint8Array, gameHash: Uint8Array): number`

Calculates the game result (crash point).

**Parameters:**
- `vxSignature`: The VX signature (as Uint8Array)
- `gameHash`: The game hash (as Uint8Array)

**Returns:**
- Crash point as a multiplier (e.g., 1.50 for 1.50x)
